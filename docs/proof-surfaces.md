# Proof surfaces: REAL, SYNTHETIC, UNSUPPORTED

Everything in this repository is labelled. Nothing is inferred, and nothing is
claimed that was not executed.

## REAL — built, executed and observed here

| Claim | Evidence |
|---|---|
| C++20 runtime library builds with zero first-party warnings under `/W4 /WX` | Release, Debug and Debug+ASan builds |
| 13 test suites plus the downstream packaging proof pass | `ctest` in all three configurations, 14/14 |
| Snapshot identity is deterministic and content addressed | `unit_snapshot`, `property_invariants` (60 seeds), `transport.two_processes_agree_on_snapshot_identity` |
| Snapshot identity is independent of source interleaving | `integration_ingest.final_state_is_independent_of_interleaving`, `property_invariants` |
| No torn views under concurrent ingest and query | `concurrency_runtime.readers_never_observe_a_torn_snapshot`, digest re-verification every read |
| Lock ordering and re-entrancy are clean | runtime auditor, asserted in `concurrency_runtime` |
| Pipeline ordering is preserved across worker counts | `the_pipeline_preserves_per_source_order` with 1, 2, 3 and 8 workers |
| Queue bounds, cancellation accounting and real drain shutdown | `the_pipeline_queue_is_bounded`, `cancellation_discards_what_it_says_it_discarded`, `draining_shutdown_processes_everything_submitted` |
| Journal integrity chain detects corruption at every layer | `unit_persistence`, `integration_restart.corruption_is_reported_and_the_runtime_still_serves` |
| A damaged journal is never repaired, truncated or deleted | `integration_restart` re-reads the file after a failed recovery |
| Restart never presents persisted evidence as fresh | `integration_restart.recovered_evidence_is_never_fresh`, `transport.restart_across_processes_degrades_freshness`, CLI end to end |
| Truncated tails are reported as truncation, not corruption | `integration_restart.truncated_tail_is_recovered_conservatively` |
| Unsupported journal format versions are refused | `unit_persistence.unsupported_format_version_is_refused_not_guessed` |
| Bounded memory, queues, history, result sets and journals | `unit_bounds`, `adversarial_input` |
| Checked arithmetic for externally derived sizes | `unit_identity.checked_arithmetic_reports_overflow` |
| Saturating arithmetic for externally supplied timestamps | `adversarial_input.clock_skew_and_extreme_times_are_handled` |
| Real independent-process transport over real pipes | `process_transport` (five tests, real `CreateProcess` with redirected stdio) |
| The tool works as an operator uses it | `e2e_cli` (eight tests) |
| The installed package is complete and consumable | `downstream_find_package`: install, independent configure, build, run, package content check |
| AddressSanitizer is available on this toolchain and actually active | `/fsanitize=address` builds link and run; the sanitizer runtime is copied next to every binary, and the full suite passes under it |
| No test timeout, sleep or polling loop exists | by inspection of `tests/` and `src/`; CTest timeouts are disabled (`TIMEOUT 0`) |
| Benchmarks measure completed work | each benchmark counts finished units and prints a checksum over its results |

## SYNTHETIC — generated by the tests and benchmarks

| Item | Origin |
|---|---|
| Every fabric, site, pod, rack, device, port, link, path and source in tests, examples and benchmarks | derived identities and hand-built observations in this repository |
| Every topology relationship, link state, port state, health value, congestion level and capacity figure | literal values chosen by the test |
| Every "source" | an in-process or in-test generator, delivered over in-process calls or a real pipe from `fabobs serve` |
| Every measurement and throughput figure | produced on this workstation at the time of the run; they are not hardware or vendor benchmarks |
| Benchmark workload shapes | chosen to exercise the runtime, not sampled from any real fabric |

Synthetic content is realistic in *shape* — sources with incarnations and
sequence numbers, generations and epochs, devices under racks under pods under
sites — but it is not a recording of anything.

## UNSUPPORTED — not built, not executed, not claimed

| Claim | Status |
|---|---|
| Interaction with any switch, ASIC, NIC, RDMA device, InfiniBand fabric or NVLink domain | not implemented |
| Any vendor protocol, management API or telemetry format | not implemented |
| Multi-host or multi-site deployment, consensus, or coordination between runtime instances | not implemented |
| Disk-full, power-loss and torn-write behaviour under a real filesystem | not tested; recovery is tested against deliberately damaged files, which is a different thing |
| Long-running soak behaviour, memory growth over days, and production throughput | not measured |
| Security properties: authentication, authorisation, transport encryption, rate limiting against a determined adversary | not implemented — the transport is a local stdio protocol |
| Operating systems other than the one used here | not built; the code is portable in shape and the build is warning-clean under MSVC, but only MSVC has been exercised |
| Compression, encryption at rest, or remote replication of the journal | not implemented |
| Formal verification, model checking or proof of the fences | not performed; the fences are tested, not proved |

## Honest summary

The **runtime** is real and thoroughly exercised. The **fabric** it is exercised
against is entirely synthetic. Any statement in this repository that reads as a
hardware, vendor or multi-host claim is out of scope and unsupported by design;
if such a statement is found, it is a documentation defect.
